# RFR-IQ — Data Provenance & Operational State Matrix

Every data element consumed or displayed within RFR-IQ maintains an explicit, immutable internal provenance contract. The system strictly forbids silent type coercion (e.g., converting a failed API or a scenario input into a "live" value).

---

## 1. Permitted Provenance States

| State | Definition | Example Application |
|---|---|---|
| **LIVE** | Directly retrieved from a verified, active, unauthenticated public API covering the specific location in real-time. | Open-Meteo Weather temperature/wind, Open-Meteo Marine wave/swell, ExchangeRate-API USD/INR rate. |
| **HISTORICAL** | Ground-truth historical data records or baseline datasets with established temporal bounds. | DS07 Freight series (2012–2019), DS01 World Bank Pink Sheet commodity history, DS05 Port specifications. |
| **INDICATIVE** | Synthetic or simulated series generated by the separate mock freight engine for scenario analysis. | Standalone freight server responses (`/api/freight/scenario`). |
| **DERIVED** | Deterministic calculations evaluated from valid, verified operational inputs using explicit domain formulas. | Berthing safety level from wave/swell thresholds, weather risk category, decision result (ENTER/WAIT/WATCH). |
| **UNAVAILABLE** | Legitimate data is inaccessible due to feed failure, network timeout, or lack of public unauthenticated coverage. | East Coast India live AIS vessel positions & queue lineups, failed network requests. |

## 3. Strict Non-Fabrication Rules

1. **No Silent Fallback**: If an external API call fails, the UI must render `UNAVAILABLE` with an option to retry. Hardcoded static defaults must never be substituted.
2. **No Geographic Substitution**: US AIS data (e.g. NOAA MarineCadastre) or European coastal feeds must NEVER be repurposed to simulate Indian port operations.
3. **No Synthetic Live Disguise**: Simulated freight generator data must always carry the `INDICATIVE` badge and never be labeled as `LIVE` spot freight.
4. **No Artificial Precision**: Random numbers (`Math.random()`) must never be used to invent operational metrics, turnaround delays, queues, or freight prices.
